---
title: "Read and download a transcript"
description: "Find completed transcriptions, preview them, download them, or continue in Analysis Chat."
---

Find a completed transcript in Transcription History to read, download, or use it in Analysis Chat.

## Find your transcription

Open **A.I. Audio Transcriber** and scroll to **Transcription History**. Use **All**, **Processing**, **Ready**, or **Failed** to filter the list. A transcription marked **Ready** can be read, downloaded, or opened in Analysis Chat.

If history cannot be loaded, select **Retry**.

If the actions are off screen, scroll the history table sideways. Expand a batch to see each filename, status, and available actions. A batch can include files that are still processing, failed, or were skipped, so check the individual file before opening it.

## Read or copy a transcript

Select **Read** beside a ready transcription. Its text appears in **Transcript Preview**. Use **Copy** below the preview to copy the text. **Reset** clears the preview.

Review the text against the recording before relying on names, speaker labels, or other important details. For example, check a participant's name and the speaker assigned to a quoted comment before using it in a report.

## Download a transcript

Select **Download** beside a ready transcription. A single-file transcription downloads as a text file. For a batch, choose the format that suits your next step:

- **CSV** for one spreadsheet-ready file containing the batch.
- **TXT** for a separate plain text file for each transcript.

You can also download the text currently shown in the preview using the **Download** button below it. If you choose separate TXT files for a batch, check your browser downloads for each file.

## Continue in Analysis Chat

Select **Chat** beside a ready transcription to start an Analysis Chat with that transcript as context. You can then ask for a summary or analysis.

## Delete a transcription

Select the delete button beside a transcription and confirm. Deleting a batch removes all transcriptions in that batch.
