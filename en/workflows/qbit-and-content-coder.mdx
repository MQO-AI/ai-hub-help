Asker Q-bit Analysis and A.I. Content Coder are separate ways to work with Survey responses, each with its own workspace and output.

## When to use each workflow

Use Q-bit Analysis to ask questions about a selected Asker capture, such as exploring a theme in its responses. Use Content Coder when you need to define categories, code responses, and check A.I. coding in a Hub project.

Creating a Q-bit Analysis capture does not automatically create a Hub Content Coder project. To bring selected Survey responses into Content Coder, use the separate Survey transfer workflow. A sender initiates a transfer in Asker, and the recipient chooses whether to create a project or review an eligible linked-project update in the Hub. Sending and accepting are separate actions; updates do not sync automatically.

For example, use Q-bit to explore a theme in an Asker capture, then separately send a selection to Content Coder if you need a project with a codebook and response-level coding. Review the fields in the resulting project: an A.I. follow-up selection can also include follow-up metadata fields.

For the Hub steps, see [Import Survey transfers](./import-survey-transfers). For Q-bit capture selection, analysis, and its results, follow the Asker guidance for your available release.

If you cannot find a transfer, confirm with the sender that it was sent to you, then open **A.I. Content Coder** and check **Survey transfers**. Contact support if it remains unavailable.
