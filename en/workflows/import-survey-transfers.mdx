---
title: Import Survey transfers into Content Coder
description: Create a project from a transfer, or review and add new answers to a linked project.
---

A Survey transfer brings selected Asker responses into A.I. Content Coder so you can work with them in a project.

## When to use each destination

Create a new project for a transfer you want to work on separately. Choose a linked project to review eligible new answers from the same question selection. The sender must send another transfer, and you must review and accept it: updates do not sync automatically.

## Before you start

You need access to A.I. Content Coder and a Survey transfer addressed to you. Save any current Coder changes and wait for other coding to finish before importing an update.

## Import a new project

1. Open **A.I. Content Coder** and select **Survey transfers**.
2. Under **Pending transfers**, check the title, sender, question count, and response-row count to find the intended transfer. Select **Choose import destination**.
3. Choose **Create a new project**, then select **Import new project**.
4. Open the new project from the project list to review its questions and begin coding. Review the imported fields before coding. A selection containing an A.I. follow-up can also include follow-up metadata fields.

The imported project is a separate copy. The transfer does not grant access to the source Survey or send an email notification. Add question context deliberately if the coding needs it.

## Add answers to a linked project

1. In Asker, send the same question selection again. In Content Coder, open **Survey transfers** and find the new transfer.
2. Select **Choose import destination**, then choose the linked project under **Update**.
3. Select **Review update**. Check the counts for new response rows, previously blank answers now filled, and unchanged answers. For example, an answer added to an existing blank is counted separately from a new respondent row.
4. If the review allows the update, select **Confirm additions to this project**. Reopen the project to load the updated data.
5. Under **Finish coding added answers**, review the retained assignments, answers to code, and maximum codes for each question. Select **Code / resume added answers** for a ready question. The saved codebook and maximum code setting are used for the added answers. Existing compatible assignments are retained.

If earlier answers changed or earlier rows are absent, the update cannot overwrite or delete them. Create a separate project to review those changes. If the saved codebook or coding has changed, review the question and run full coding instead of combining versions.

Completed human reviews remain available against their original coding version. Their decisions do not automatically replace A.I. assignments in the updated dataset.

## If an update is interrupted

Use **Refresh** in **Survey transfers** to check the current state. If added-answer coding stops, completed batches are saved and you can resume there. If the review is no longer current, review the update again before confirming. If the transfer or linked projects cannot be loaded, refresh and retry. Contact support if the problem continues.
